# Interior Floorplan

Rewrite of [wy51ai/floorplan-3d](https://github.com/wy51ai/floorplan-3d) in React with editable room dimensions and preservation of the original procedural furniture models.

## Current state

The React application has not been implemented yet. This repository contains the complete original application in `legacy/index.html`, its MIT license, an implementation brief in `CLOUD_TASK.md`, and source analysis in `MIGRATION.md`.

Open `legacy/index.html` in a browser to run the reference application. Its Three.js dependencies load from a CDN and require internet access.

## Cloud implementation

Connect this repository to a Codex Cloud environment. Start a coding task with:

> Implement the React application described in CLOUD_TASK.md. Read MIGRATION.md and legacy/index.html first. Preserve the original procedural furniture models and default apartment. Complete and verify the implementation, then create a pull request with the changes.

Uploading a repository alone does not start a cloud coding task.

## Getting the result locally

After reviewing and merging the cloud pull request, run `git pull --ff-only origin main` in this repository. The implementation task must document installation and development commands in this README.
